# VERACRUZ MOTO WORLD

Videojuego de motocicletas de mundo abierto basado en Veracruz, México.

## Características
- Mundo abierto de Veracruz.
- Motocicletas de doble propósito.
- Tráfico realista.
- Multijugador de hasta 8 jugadores.
- Modo individual sin internet.
- Persecuciones policiales.
- Gráficos 3D.
- Controles táctiles para Android.
