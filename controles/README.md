# Controles táctiles

## Controles de conducción
- Acelerar.
- Frenar delantero.
- Frenar trasero.
- Girar a la izquierda.
- Girar a la derecha.
- Inclinar motocicleta.
- Hacer caballito.
- Bajar de la motocicleta.

- Cambiar tamaño.
- Cambiar transparencia.
- Guardar configuración.
