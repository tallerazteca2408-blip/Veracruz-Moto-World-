# Sistema de cámaras

## Cámara en tercera persona
- Vista detrás de la motocicleta.
- Cámara dinámica al girar.
- Seguimiento de saltos y derrapes.

## Cámara en primera persona
- Vista desde el conductor.
- Manubrio visible.
- Tablero de instrumentos.

## Configuración
- Ajustar distancia.
- Ajustar sensibilidad.
- Cambiar entre primera y tercera persona.
